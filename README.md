## 学习路线（概览）

1. **基础补强（0-6 个月）**：C 语言、计算机体系结构、存储层级
2. **SSD 技术入门（6-12 个月）**：NAND Flash、SSD 架构、NVMe 协议
3. **FTL 核心算法（1-2 年）**：地址映射、磨损均衡、垃圾回收、ECC/LDPC
4. **固件工程实践（2-3 年）**：NVMe 协议栈、掉电保护、性能优化
5. **高级进阶（3 年+）**：企业级 SSD、多核/QoS、NVMe-oF
