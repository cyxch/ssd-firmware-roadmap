# Mini SSD 模拟器（综合项目 · 交付物）

把 15 周 SSD 固件知识串成一条**完整可运行**的固件链路模拟器。

## 一句话

一个用 C 语言实现的"软件 SSD"：有 NAND、有 FTL、有 NVMe 命令接口、有 DRAM 缓存与掉电保护、有 QoS 调度、有 SMART 遥测——跑一轮端到端工作负载，观察数据如何从主机写到 NAND、坏块如何跳过、垃圾回收如何搬移、掉电如何恢复。

## 编译运行

```bash
gcc -O2 -Wall -Wextra -o ssd mini_ssd.c && ./ssd
```

## 架构分层（对应学习周）

```
主机应用(工作负载)
  │  READ/WRITE/FLUSH/POWER_LOSS/POWER_ON 命令
  ▼
NVMe 命令接口 + QoS 优先级队列     ← 第12周 / 第14周
  │  高优先级命令(管理/FLUSH)插队
  ▼
DRAM 写缓存(Write-back) + 掉电保护 ← 第13周
  │  FLUSH 提交 / 掉电丢未提交 / 上电重建
  ▼
FTL 层: L2P 映射 + 垃圾回收 + 磨损均衡 ← 第11周
  │  out-of-place 写 / GC 搬移 / 动态+静态磨损均衡
  ▼
NAND 层: 块/页模型 + 擦写 + 坏块       ← 第10周
  ▼
SMART 遥测报告                         ← 第15周
```

## 功能清单

| 模块 | 实现要点 |
|------|---------|
| NAND | 32 块 x 8 页 = 256 物理页, 2 个出厂坏块, 页读写擦, P/E 计数 |
| FTL | L2P 映射表, out-of-place 更新, 低水位 GC(victim=有效页最少), 动态+静态磨损均衡, 写放大 WAF |
| 缓存 | 16 条 write-back DRAM 缓存, 命中更新, 满则自动刷出(eviction) |
| 命令接口 | READ/WRITE/FLUSH/POWER_LOSS/POWER_ON/SMART, 优先级队列(高优先级插队) |
| 掉电保护 | 未提交缓存数据丢失(未确认语义), 上电扫描 OOB 重建映射表, CRC 校验 |
| SMART | 读写次数, WAF, GC 搬移量, 缓存命中, ECC 失败, 坏块, P/E 分布, 剩余寿命 |

## 工作负载（main 中 6 个阶段）

1. **命令路径演示**：写后立即读(缓存命中) + 高优先级 READ 插队
2. **阶段1** 顺序写 LBA 0..63，读回校验
3. **阶段2** 随机写全 LBA 空间，读回校验
4. **阶段3** 大量随机重写 → 触发垃圾回收 → 观察写放大 WAF
5. **阶段4** 冷数据块 + 10 轮静态磨损均衡
6. **阶段5** 掉电(8 条未提交丢失) + 上电重建 → 已提交数据完好性校验
7. **阶段6** SMART 健康报告

## 扩展方向

- 把 128 个 LBA 换成块设备模拟(512B 扇区 + 多页连续传输)
- 加入真实 ECC(BCH/LDPC) 与更多位错误注入
- 用多命名空间(第15周)做多租户 QoS 隔离
- 串上真正的环形缓冲区 SQ/CQ(第9/12周)替代数组命令队列
