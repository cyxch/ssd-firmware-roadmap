# Mini SSD 模拟器 · 项目运行报告

> 综合项目交付物 · 15 周知识闭环 · 编译环境 `gcc -O2 -Wall -Wextra`

## 1. 项目概述

`mini_ssd.c`（单文件，约 590 行）实现一个"软件 SSD"：包含 NAND、FTL、NVMe 命令接口、DRAM 写缓存与掉电保护、QoS 优先级调度、SMART 遥测。运行一轮端到端工作负载，验证数据从主机到 NAND 的完整通路与掉电恢复能力。

**编译运行**

```bash
gcc -O2 -Wall -Wextra -o ssd mini_ssd.c && ./ssd
```

## 2. 架构图

```
主机应用(工作负载)
   │  READ / WRITE / FLUSH / POWER_LOSS / POWER_ON 命令
   ▼
NVMe 命令接口 + QoS 优先级队列         ← 第12周 / 第14周
   │  高优先级命令(管理/FLUSH)插队
   ▼
DRAM 写缓存(Write-back) + 掉电保护      ← 第13周
   │  FLUSH 提交 / 掉电丢未提交 / 上电重建
   ▼
FTL 层: L2P 映射 + GC + 磨损均衡        ← 第11周
   │  out-of-place 写 / GC 搬移 / 动态+静态磨损均衡
   ▼
NAND 层: 块/页 + 擦写 + 坏块            ← 第10周
   ▼
SMART 遥测报告                          ← 第15周
```

## 5. 关键指标（SMART 报告实测值）

| 指标 | 值 | 说明 |
|------|----|----|
| 主机读 | 412 次 | 含校验读 |
| 主机写 | 1411 次 | 经 DRAM 缓存 |
| NAND 编程 | 1695 页 | 含 GC 搬移 244 页 |
| **写放大 WAF** | **1.20** | NAND 实际写 / 主机写 |
| 缓存命中 | 2 次 | 写后立即读 |
| ECC 校验失败 | 0 次 | 完整性零错误 |
| 坏块 | 2 / 32 | 出厂坏块被跳过 |
| P/E 分布 | min 5 / 平均 7 / max 17 | 磨损均衡生效 |
| 剩余寿命 | 83% | 按 max P/E 估算 |
| 上电恢复 | 128 个有效页 | 扫描重建映射表 |

## 6. 指标解读

- **WAF 1.20**：随机重写导致 out-of-place 更新堆积无效页，GC 额外搬移 244 页；相比顺序写（≈1.0）多耗约 20% NAND 寿命与带宽。
- **剩余寿命 83%**：磨损最重的块 P/E = 17 / 上限 100；动态 + 静态磨损均衡把 P/E 控制在小范围（5~17）内。
- **掉电语义**：掉电丢失的 8 条均为"未提交"缓存数据（主机未得到确认），已确认数据在上电扫描重建后完整可读——符合 NVMe "已确认"可靠性模型。

## 7. 结论与下一步

模拟器完整复现了 SSD 固件的核心机制，数据完整性在正常与掉电两种场景下均通过校验。扩展方向：块设备扇区模拟、真实 ECC(BCH/LDPC)、多命名空间 QoS 隔离、环形缓冲区 SQ/CQ。
