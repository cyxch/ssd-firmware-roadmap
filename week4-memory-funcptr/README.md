# Week 4 · 内存管理与函数指针

SSD 固件方向学习计划 · 第 4 周（内存管理与函数指针）

## 本周目标

- 理解内存四区（栈/堆/全局区/代码区）
- 掌握 malloc / free、内存泄漏与避免方法
- 掌握函数指针与回调机制（嵌入式中断/驱动常用）
- **交付物 1**：环形缓冲区（生产-消费模型）
- **交付物 2**：内存池（空闲链表，固定大小块）
- **综合项目**：用结构体+指针+函数指针写命令解释器

## 目录结构

| 文件 | 主题 |
|------|------|
| `01_memory_layout.c` | 内存四区、变量存放位置 |
| `02_malloc_free.c` | malloc/free、悬垂指针、内存泄漏 |
| `03_function_pointers.c` | 函数指针与回调 |
| `04_ring_buffer.c` | 环形缓冲区（交付物） |
| `05_memory_pool.c` | 内存池（交付物） |
| `06_command_interpreter.c` | 综合项目：命令解释器 |

## 编译运行

```bash
gcc -Wall -Wextra -o rb 04_ring_buffer.c && ./rb
gcc -Wall -Wextra -o mp 05_memory_pool.c && ./mp
```
